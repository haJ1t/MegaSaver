# Cache Suffix Audit and Output-Route Contract Amendment

> **Date:** 2026-08-02
> **Status:** APPROVED — the user authorized continuous implementation until completion on 2026-08-02.
> **Risk:** HIGH — this adds public CLI analysis, private hook state evolution, and advice that must remain policy-safe and recoverable.
> **Amends:** 2026-08-01-cache-write-reduction-design.md §§6–8, 2026-08-01-cache-suffix-audit-plan.md, 2026-08-01-output-route-adviser-plan.md, and 2026-08-02-batch-read-adviser-hardening-design.md.

## 1. Purpose and boundary

The suffix audit must expose measured cache-token composition and static
configuration risks without treating any share as avoidable cost. The
output-route adviser must suggest only an action that the current product can
actually execute, preserve command and path privacy, and never expand command
policy merely to make an advice look useful.

This amendment deliberately accepts false negatives. It creates neither a
cost-savings claim nor a model-performance claim; the approved fixed-transcript
real-API A/B is still the only savings gate.

## 2. Phase 3: suffix-audit contract

Ordinary mega cache --json remains unchanged. Only mega cache --suffix-audit
returns this additional closed object:

    suffixAudit: {
      composition: {
        scope: "measured-global";
        status: "measured" | "no-usage";
        totalMeasuredTokens: number;
        cacheCreationShare: number | null;
        cacheReadShare: number | null;
        inputShare: number | null;
        outputShare: number | null;
      };
      settingsStatus: "ok" | "absent" | "unreadable" | "malformed";
      risks: CacheSuffixRisk[];
    }

The denominator is exactly cache-creation + cache-read + input + output
tokens. It is measured-global only. A zero denominator produces no-usage and
null shares, never zero percent. Text mode prints cache write share: n/a (no
measured global usage), but still renders static risks.

The existing Pro gate runs before either usage or settings I/O. Settings reads
return a discriminated result:

- absent produces no settings risk;
- unreadable produces only settings_unreadable;
- malformed JSON or a non-object root produces only settings_malformed;
- ok is the only branch inspected for settings-derived risks.

No risk object has a free-text detail. The closed risk union is:

    settings_unreadable
    settings_malformed
    duplicate_megasaver_hook
    foreign_custom_base_url
    owned_route_missing_first_party_flag
    generated_output_byte_variance

Duplicate detection emits one result per hook-event/subcommand pair, with a
count of recognized first-party command objects. It normalizes only owned
launchers through the connector matcher. Different owned subcommands in one
event are not duplicates; arbitrary strings that resemble mega are not owned.

A foreign custom base URL and a missing first-party flag are distinct risks.
The flag is meaningful only for Mega Saver's known owned forwarding route.
Generated byte variance is a same-process binary check: render independent
hook-settings and connector-block fixtures twice and compare their UTF-8 bytes.
The result may contain only code and surface. It never emits rendered bytes,
digests, fixture input, URLs, paths, commands, secrets, or error text.

All risk ordering is deterministic. Free-tier invocations call neither reader.
Zero usage does not suppress suffix-audit static analysis.

## 3. Phase 4: executable output-route advice only

Do not expand packages/policy. The adviser may classify only two content-free
command grammars which existing mega output exec can preflight and execute:

    grep := grep (-r | -R) MODIFIER* -e SAFE_WORD -- REL_PATH+
    find := find REL_PATH [ -type (f | d | l) ] [ -print ]
    MODIFIER := -n | -H | -i | -F | -w | -x

Input is at most 4,096 UTF-8 bytes and 64 tokens. ASCII space is the only
separator. A fixed ASCII-safe token class is used. Each path is relative,
contains no dot-dot segment, names an existing directory below the canonical
workspace, and has no ambiguous shell syntax. Reject option clusters,
absolute executables, quotes, escapes, glob/brace/tilde expansion, controls,
assignments, substitutions, pipes, redirects, comments, operators, unlisted
options/actions, rg, git, nonrecursive grep, and mutating find forms.

Recursive grep over explicit directories and a directory find are candidates
for large output. That is a content-free eligibility class, not a measured
output size or savings prediction. Exact reconstructed argv must pass the
current policy and permissions preflight; execution rechecks policy later.

Before consuming one family offer, all of these must hold:

1. POSIX and the default store only. A baked non-default store suppresses this
   branch without weakening batch-read advice.
2. One uniquely resolved registered project whose canonical root equals the
   hook cwd exactly.
3. Exactly one open claude-code Mega Saver session for that project. The Claude
   hook session is state scope only; it is not the registry UUID.
4. The effective session has storeRawOutput true.
5. Settings/permissions resolve and the exact argv is accepted.

Otherwise response and state change are both empty. A successful response may
name only the selected registry session UUID and instruct the agent to rerun
the same approved command through mega output exec; it must not restate the
command, argv, pattern, cwd, project/store path, permission details, hook
session, or any current-input text. It adds no permissionDecision or
updatedInput.

Read, Grep, and Glob retain filesystem target handling. Bash is a separate,
bounded command branch using only tool_input.command, canonical cwd, and safe
hook session; it must never flow through a file-path extractor.

## 4. State evolution and hook installation

Storage topology v3 from the fair-GC amendment is independent of JSON state
version. Output-route advice evolves a valid capsule state atomically from:

    {
      version: 2;
      offeredDirectoryKeys: string[];
      recent: CacheAdviceCall[];
    }

to:

    {
      version: 3;
      offeredDirectoryKeys: string[];
      offeredOutputRouteFamilies: ("grep" | "find")[];
      recent: CacheAdviceCall[];
    }

Under the existing capsule transaction, exact v2 gets an empty family list and
is durably written as v3. A qualifying Bash call records one family and emits
only after the same durable write succeeds. Malformed, v1, and unknown future
versions remain untouched and suppress advice. The 32,768-byte limit, 64
directory keys, 128 calls, two unique family tags, opaque record identity, and
fair-GC contract remain mandatory. Persist no route session UUID, command,
argv, pattern, raw path, workspace, or store.

The owned Claude matcher adds Bash without duplicating current owned hooks or
altering foreign hooks. Windows continues to omit cache advice entirely.

## 5. Evidence

- suffix-audit covers measured and no-usage composition, all four settings
  states, deterministic risk ordering, duplicate granularity, forced byte
  variance, free-tier no-I/O, and serialized privacy fixtures;
- output routing accepts exactly the stated grammar and rejects all shell,
  path-escape, unsupported, and mutating forms;
- every accepted argv passes existing policy; ambiguous/wrong/ended sessions,
  non-root cwd, custom store, raw-output disabled, and permission failures
  return empty with no family consumption;
- v2 migration, malformed/future preservation, same-family concurrency,
  Windows absence, hook matcher preservation, bundle and packed-bin execution,
  privacy scan, independent reviews, and Node 22 pnpm verify pass.
