Questions, answered

What exactly am I buying?

Historical savings analytics + waste/efficiency insights on top of the free open-source Mega Saver CLI. mega savings history/insights/forecast, CSV/JSON export. The core CLI stays free (MIT); Pro is the analytics layer. Offline, unforgeable Ed25519 license.

What's free and what's Pro?

The Mega Saver CLI — context filtering, session tools, local usage records — is free and MIT-licensed, and stays that way. Pro adds the analytics layer: mega savings history, insights, forecast, and CSV/JSON export.

Which coding agents does it work with?

Mega Saver is agent-agnostic: Claude Code, Codex, Cursor, Aider, and any CLI agent you can point at it. Pro analyzes the usage the CLI records — it doesn't care which agent produced it.

Does any of my data leave my machine?

No. Usage is recorded locally by the free CLI, and Pro's analytics run locally on those records. The license itself is verified offline via an Ed25519 signature, so activation doesn't need a server either.

How does the license arrive, and can I cancel?

Your key arrives by email right after checkout; activate it with mega license activate <key>. The subscription is billed monthly through Gumroad and you can cancel anytime from your Gumroad account — billing simply stops.
